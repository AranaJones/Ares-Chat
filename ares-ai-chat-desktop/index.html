AI_Helper is an LLM-powered chat participant. Ares hashurl room targeting is supported locally; real Ares room joins and live channel discovery are not.
Settings

Enter your Anthropic API key to enable AI_Helper. Get one at console.anthropic.com. It's stored only on this device (localStorage), never sent anywhere except directly to Anthropic's API.

Network - supernode probe

This does a plain TCP connect check against Ares supernode IPs - the same first step the real client does before login. It does not log in or fetch chat rooms (that part of the protocol isn't confirmed yet). Paste host:port pairs (one per line) or load a real SNodes.dat from an existing Ares Galaxy install.
